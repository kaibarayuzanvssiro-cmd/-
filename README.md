# GitHub連携デモ（C版）

このリポジトリは、**プログラム初心者**と**GitHub初心者**向けの最小サンプルです。  
やっていることは「2 + 3 を計算して表示する」だけです。

---

## このリポジトリにあるもの

- `app.c`  
  C言語のプログラム本体。`2 + 3 = 5` を表示します。
- `test.sh`  
  自動テスト用スクリプト。`app.c` をビルドして実行し、出力が正しいか確認します。
- `.github/workflows/c-tests.yml`  
  GitHub Actionsの設定。`push` / `pull request` のたびに `./test.sh` を自動実行します。

---

## 実行方法（ローカル）

### いちばん簡単な方法

```bash
./test.sh
```

これで次の3つを自動で行います。
1. `app.c` をコンパイル
2. 実行
3. 出力が `2 + 3 = 5` か判定

成功すると `OK` が表示されます。

### 手動で1つずつ実行する方法

```bash
gcc -Wall -Wextra -Werror app.c -o app
./app
```

---

## GitHub初心者向け：何が便利？

### 1. コードをGitHubにpushすると自動チェックされる
`main` ブランチに直接入れる前に、GitHub Actionsがテストしてくれます。

### 2. Pull Request（PR）で安全にレビューできる
PRを作ると、テスト結果が見えるので「この変更で壊れていないか」を確認しやすいです。

### 3. 変更履歴が残る
「いつ・どの変更で動かなくなったか」を後から追いやすくなります。

---

## 最初の学習ステップ（おすすめ）

1. `app.c` の `a` と `b` の値を変える（例: `10` と `20`）
2. `./test.sh` を実行して結果を見る
3. コミットしてPRを作る
4. GitHub上でActionsが通るのを確認する

この繰り返しで、Cの基本とGitHubの開発フローを同時に学べます。
